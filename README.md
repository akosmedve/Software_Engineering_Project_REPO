# ProcrastiTask

ProcrastiTask is a small task management application for
individual software developers.

The application can save the following task-information:

- Current development state
- Next development step
- Source file
- Component
- Git branch
- Technical notes

## Technology

- C#
- WPF
- .NET 5.0
- JSON persistence

### Features

- Create tasks
- View tasks
- Edit tasks
- Delete tasks
- Task status and priority
- Development context
- Local JSON persistence
- Visual indication of high-priority tasks
